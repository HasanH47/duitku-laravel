# Verifikasi sandbox — 22 Oktober 2026

SDK berhasil membaca daftar metode pembayaran dan membuat invoice API serta POP menggunakan HMAC-SHA256. Status invoice API terkonfirmasi pending. Status invoice POP baru belum berhasil diverifikasi melalui endpoint V2.

Pengujian memakai proyek sandbox yang diberikan pemilik repository. Kredensial, payload bertanda tangan, nomor VA, reference, dan URL pembayaran tidak disimpan dalam dokumen atau fixture repository. Semua request memakai host sandbox dengan timeout 15 detik dan retry dinonaktifkan.

| Operasi SDK | Hasil nyata |
| --- | --- |
| `paymentMethods(10000)` | Berhasil; 26 metode dikembalikan |
| `checkout()` | Invoice Rp10.000 memakai channel BC berhasil; reference dan URL pembayaran terisi |
| `checkStatus()` untuk invoice API | Berhasil; status `01`, reference cocok dengan invoice |
| `pop()->createTransaction()` | Invoice Rp10.000 tanpa channel pilihan berhasil; reference dan URL pembayaran terisi |
| Lookup V2 untuk invoice POP baru | HTTP 404; penyebab belum diisolasi |
| `checkStatuses()` untuk kedua invoice | Dua hasil dipertahankan: satu sukses dan satu HTTP error, sesuai kontrak partial failure |

Invoice memakai data pelanggan sintetis dan expiry 10 menit. Tidak ada pembayaran yang dilunasi, instruksi transfer dana, atau request ke host production.

Daftar metode masih memuat GQ pada akun ini, meskipun changelog mendokumentasikan pengurangan channel tersebut. Temuan ini tidak membuktikan invoice GQ masih didukung. SDK tetap menandainya deprecated dan menolak invoice baru GQ.

## Batas kesimpulan

Hasil ini membuktikan penerimaan signature pada request yang berhasil di akun sandbox tersebut. Hasilnya tidak mencakup semua akun, channel, nominal, protokol legacy, atau production.

HTTP 404 dari lookup invoice POP tidak diubah menjadi pending, paid, atau failed. Dokumentasi POP tidak menetapkan endpoint status tersendiri; wrapper masih memakai status API V2. Apakah order menjadi tersedia setelah pemilihan channel atau langkah lain masih perlu diverifikasi. Jangan menganggap setiap invoice POP baru dapat langsung dibaca lewat API V2.

Belum diuji: pelunasan sandbox, callback HTTP dari provider, signature callback provider, transisi paid/failed nyata, tokenisasi kartu, disbursement, dan akun production. Test lokal memakai callback sintetis dan dibedakan dari pengujian provider.

Acuan: [API V2](https://docs.duitku.com/api/id/) dan [POP](https://docs.duitku.com/pop/id/). Catatan ini melengkapi [audit awal](./2026-10-22-audit).
